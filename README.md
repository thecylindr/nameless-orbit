## ✨ Возможности

| | |
|---|---|
| 🔐 **Сопряжение** | общий код сверки на обоих экранах, шифрованный канал (X25519 · ChaCha20 · HMAC-SHA256), повторное подключение само |
| 📁 **Файлы и буфер** | отправка с согласия получателя, текст из буфера одним нажатием |
| 🔔 **Уведомления и «найти устройство»** | сообщения друг другу, звонок до нажатия «Нашёл» |
| 🖥 **Показ экрана** | H.264 на видеокарте или процессоре, тайлы, JPEG; качество подстраивается под сеть; информационная полоса показывает, кому и что показывается |
| 🪟 **Второй экран** | устройство становится ещё одним монитором компьютера на Hyprland: свой стол, масштаб, повтор монитора, защита при потере связи |
| 🔊 **Звук** | звук компьютера на другое устройство — без сжатия или Opus; отдельное разрешение для каждого устройства |
| 🖱 **Управление** | мышь и клавиатура с телефона; красная полоса, пока управление включено |
| 🛡 **Доверие** | «Спрашивать» · «Доверенное» · «Полное доверие» — вы решаете, о чём вас спрашивать |
| 🌐 **Языки** | русский и English, выбор при первом запуске |

Всё работает **только в вашей сети** и только между **вашими** устройствами: каждое подтверждается кодом на обоих экранах.

## 📦 Установка

**Arch Linux** (из AUR или из этого репозитория):

```bash
yay -S nameless-orbit-git                         # если пакет уже опубликован в AUR
# или вручную из исходников репозитория:
cd packaging/arch && makepkg -si
```

**Другие дистрибутивы** — соберите из исходников ([ниже](#-сборка-из-исходников)); ярлык в меню ставит `cmake --install`.

**Android** — готовый APK в разделе [Releases](https://github.com/thecylindr/nameless-orbit/releases). Разрешите установку из этого источника и откройте приложение; при первом запуске оно предложит выбрать язык и выдать разрешение на уведомления.

**С NameLess UI** — оболочка сама видит запущенный Orbit: значок в баре, лента устройств, плитка и виджет ([nameless-ui](https://github.com/thecylindr/nameless-ui)).

## 🔄 Обновление

- **Arch**: `yay -Syu` (пакет `nameless-orbit-git` обновляется вместе с системой).
- **Из исходников**: `git pull && cmake --build build && cmake --install build`.
- **Android**: скачайте свежий APK из Releases и установите поверх. Данные и сопряжённые устройства сохраняются; если приложение пришлось **удалить**, телефон получит новый идентификатор — при сопряжении Orbit сам перенесёт доверие и разрешения со старой записи.

> Обновляйте приложение на обоих устройствах: версии, сильно отличающиеся друг от друга, могут не понимать новых запросов (например, второго экрана).

## 🚀 Быстрый старт

1. Откройте Orbit на обоих устройствах в одной сети — они найдут друг друга сами.
2. Сверьте код и нажмите «Коды совпадают — сопрячь» на каждом.
3. Откройте страницу устройства. Чтобы смотреть экран или делать второй, включите там разрешение **«Демонстрация экрана»**.

Подробности — в [руководстве](docs/USAGE.md).

## 🛠 Сборка из исходников

Нужны: Qt 6 (base, declarative, multimedia, svg, wayland), CMake ≥ 3.16, Ninja. Для видео на ПК — ffmpeg (libavcodec), для показа экрана — wf-recorder, для звука — libpulse (`parec`).

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
sudo cmake --install build        # или: -DCMAKE_INSTALL_PREFIX=$HOME/.local
```

Android — через Qt for Android (Qt Creator, комплект Android arm64-v8a); исходники платформенной части — в `android/`.

```
i18n/        английский перевод (en.json)

docs/        руководство
```
